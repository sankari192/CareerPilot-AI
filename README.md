# CareerPilot-AI

An AI-powered Career Guidance and Resume Analysis web application that helps students identify suitable career paths, evaluate their resumes, and receive personalized learning roadmaps based on their interests and skills.

---

## 📌 Overview

AI Career Guide is a Flask-based web application designed to assist students in making informed career decisions. The platform combines a career assessment quiz with an intelligent resume analyzer to recommend suitable career domains and identify missing technical skills required for specific job roles.

---

## ✨ Features

- 🎯 Career Assessment Quiz
- 📄 Resume PDF Upload & Analysis
- 🤖 AI-Based Career Recommendation
- 📊 Skill Gap Identification
- 🛣️ Personalized Learning Roadmap
- 💼 Company Recommendations
- 📈 Placement Readiness Insights
- 🎨 Responsive Modern UI

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/AI-Career-Guide.git
```

Move into the project directory

```bash
cd AI-Career-Guide
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install the required packages

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```

## 📄 Resume Analysis

The Resume Analyzer extracts text from uploaded PDF resumes and:

- Detects technical skills
- Matches skills with the selected job role
- Identifies missing skills
- Suggests improvements
- Generates a structured skill report

## 🧠 Career Quiz

Users answer a simple interest-based quiz to receive:

- Suitable career recommendation
- Learning roadmap
- Required skills
- Suggested companies
